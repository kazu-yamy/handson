# Next.js トラック

Next.js（TypeScript + App Router）を使ったフロントエンド開発を学ぶトラックです。Storybook を使ったコンポーネントカタログの構築も、このトラックの項目として扱います。

## カリキュラム表

| 番号 | タイトル | 到達目標 | 所要時間 | 状態 |
| --- | --- | --- | --- | --- |
| 01 | 環境構築とプロジェクト作成 | Node.js と Next.js の環境を整え、`create-next-app` でプロジェクトを作成できる | 30分 | 準備中 |
| 02 | App Router の基礎とファイルベースルーティング | ページ・レイアウト・ネストルーティングを実装できる | 45分 | 準備中 |
| 03 | サーバーコンポーネントとデータ取得 | サーバーコンポーネントで `fetch` を使ったデータ取得ができる | 45分 | 準備中 |
| 04 | クライアントコンポーネントと状態管理 | `"use client"` の使い分けと `useState` などのフック活用ができる | 45分 | 準備中 |
| 05 | Storybook でのコンポーネントカタログ構築 | Storybook を導入し、コンポーネント単位で開発・確認できる | 45分 | 準備中 |
| 06 | スタイリングとレイアウト実装 | CSS Modules / SCSS を使ったスタイリングができる | 30分 | 準備中 |
| 07 | テストの導入 | Vitest / Testing Library で基本的なテストを書ける | 45分 | 準備中 |
