# Axum トラック

Rust の Web フレームワーク Axum を使った API 開発を学ぶトラックです。
01〜06 で Web API の基本的な部品を学びます。07〜17 では、その API を認証・テスト・コンテナ化・CI を備えた API サーバー「Handson Blog API」に育てていきます。

## カリキュラム表

進捗は Obsidian の Projects/handson/progress.md で管理する。
