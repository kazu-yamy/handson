エラーハンドリングとバリデーション

  • ⏱ 所要時間: 45分
  • 📊 難易度: 入門
  • 👤 対象: 05 で DB を使った CRUD の API を作り、次にエラーの応答を分かりやすくし、不正な入力を弾けるようにしたい人
  • 📋 前提: Rust の基本文法（enum と match・Result と ? 演算子・トレイトの実装）、cargo run と curl の基本操作
  • 🔗 前提となる項目: 05: DB 接続と CRUD

🎯 このレッスンで学ぶこと

  • 独自のエラー型 AppError を定義し、IntoResponse を実装して、ステータスコードと JSON の本文を返す
  • From を実装して ? でエラーを変換し、ハンドラから map_err をなくす
  • 入力値を検証するメソッドを書き、不正な値を 422 で返す
  • Json extractor の拒否（JsonRejection）を AppError で受け止め、エラーの本文の形式をそろえる
  • IntoResponse を実装していない型を返すと、ハンドラとして使えないことをコンパイルエラーから確かめる

概要

05 の API は、エラーのときに StatusCode だけを返していました。そのため 404 や 500 の本文は空で、クライアントには原因が伝わりません。 また、Json extractor が不正なリクエストを拒否したときの本文は text/plain で、正常時の JSON と形式がそろっていません。 このレッスンでは、独自のエラー型 AppError を作ってハンドラが返すエラーの応答を {"error": "..."} という JSON にそろえ、名前のバリデーションも追加します。

このレッスンの完成時には、エラーの応答が次のように変わります。ルートの構成は 05 と同じです。

状況ステータス05 までの本文06 の本文
指定した id のユーザーがいない（GET / PUT / DELETE）404なし{"error":"user not found"}
DB の操作に失敗した500なし{"error":"internal server error"}
name が空・空白だけ・前後の空白を除いて 51 文字以上（POST / PUT）422（検証していないので、そのまま保存される）{"error":"name must not be empty"} など
JSON の拒否（content-type なし・構文エラー・型の不一致）415 / 400 / 422text/plain のメッセージ同じメッセージを {"error": ...} に包んだ JSON
どのルートにもマッチしないパス404Not Found{"error":"route not found"}
ℹ️

使用バージョン

Rust（rustc）1.98.1 / cargo 1.98.1（Rust edition 2024）で動作を確認しています。クレートのバージョンは axum 0.8.9 / tokio 1.53.1 / serde 1.0.229 / serde_json 1.0.151 / sqlx 0.9.0 です。いずれも 05 から変わりません。 バージョンは執筆時点（2026年9月）のものです。このレッスンでは新しいクレートを追加しません。エラー型は、axum に含まれる IntoResponse と JsonRejection、serde_json の json! だけで組み立てます。

2

Rust src/main.rs 
use axum::{
    Extension, Json, Router,
    extract::{Path, Query, Request, State},
    http::StatusCode,
    middleware::{self, Next},
    response::{IntoResponse, Response},
    routing::{get, post, put},
};
use serde::{Deserialize, Serialize};
use serde_json::json;
use sqlx::SqlitePool;
use std::collections::HashMap;
use std::time::Instant;

#[derive(Clone, Serialize, sqlx::FromRow)]
struct User {
    id: i64,
    name: String,
}

#[derive(Deserialize)]
struct CreateUser {
    name: String,
}

#[derive(Clone)]
struct AppState {
    pool: SqlitePool,
}

#[derive(Clone)]
struct AppConfig {
    app_name: String,
}

enum AppError {
    NotFound,
    Validation(String),
    Database(sqlx::Error),
}

impl IntoResponse for AppError {
    fn into_response(self) -> Response {
        let (status, message) = match self {
            AppError::NotFound => (StatusCode::NOT_FOUND, "user not found".to_string()),
            AppError::Validation(message) => (StatusCode::UNPROCESSABLE_ENTITY, message),
            AppError::Database(error) => {
                eprintln!("database error: {error}");
                (
                    StatusCode::INTERNAL_SERVER_ERROR,
                    "internal server error".to_string(),
                )
            }
        };
        (status, Json(json!({ "error": message }))).into_response()
    }
}

impl From<sqlx::Error> for AppError {
    fn from(error: sqlx::Error) -> Self {
        AppError::Database(error)
    }
}

#[tokio::main]
async fn main() {
    let pool = SqlitePool::connect("sqlite://app.db?mode=rwc")
        .await
        .unwrap();

    sqlx::migrate!().run(&pool).await.unwrap();

    let state = AppState { pool };

    let protected_users = Router::new()
        .route("/users", post(create_user))
        .route("/users/{id}", put(update_user).delete(delete_user))
        .route_layer(middleware::from_fn(require_api_key));

    let app = Router::new()
        .route("/", get(root))
        .route("/health", get(health))
        .route("/users", get(list_users))
        .route("/users/{id}", get(get_user))
        .merge(protected_users)
        .route("/users/{user_id}/posts/{post_id}", get(get_user_post))
        .route("/search", get(search))
        .fallback(not_found)
        .layer(Extension(AppConfig {
            app_name: "Handson Axum".to_string(),
        }))
        .layer(middleware::from_fn(log_request))
        .with_state(state);

    let listener = tokio::net::TcpListener::bind("127.0.0.1:3000")
        .await
        .unwrap();
    println!("listening on {}", listener.local_addr().unwrap());
    axum::serve(listener, app).await.unwrap();
}

async fn log_request(req: Request, next: Next) -> Response {
    let method = req.method().clone();
    let uri = req.uri().clone();
    let start = Instant::now();

    let response = next.run(req).await;

    let elapsed = start.elapsed();
    println!("{method} {uri} -> {} ({elapsed:?})", response.status());
    response
}

async fn require_api_key(req: Request, next: Next) -> Response {
    let is_valid = req
        .headers()
        .get("x-api-key")
        .and_then(|value| value.to_str().ok())
        == Some("secret");

    if !is_valid {
        return (StatusCode::UNAUTHORIZED, "invalid or missing x-api-key").into_response();
    }

    next.run(req).await
}

async fn root(Extension(config): Extension<AppConfig>) -> String {
    format!("Hello from {}", config.app_name)
}

async fn health() -> Json<serde_json::Value> {
    Json(json!({ "status": "ok" }))
}

async fn list_users(State(state): State<AppState>) -> Result<Json<Vec<User>>, AppError> {
    let users = sqlx::query_as::<_, User>("SELECT id, name FROM users ORDER BY id")
        .fetch_all(&state.pool)
        .await?;
    Ok(Json(users))
}

async fn create_user(
    State(state): State<AppState>,
    Json(payload): Json<CreateUser>,
) -> Result<(StatusCode, Json<User>), AppError> {
    let user = sqlx::query_as::<_, User>("INSERT INTO users (name) VALUES (?) RETURNING id, name")
        .bind(&payload.name)
        .fetch_one(&state.pool)
        .await?;
    Ok((StatusCode::CREATED, Json(user)))
}

async fn get_user(
    State(state): State<AppState>,
    Path(id): Path<i64>,
) -> Result<Json<User>, AppError> {
    let user = sqlx::query_as::<_, User>("SELECT id, name FROM users WHERE id = ?")
        .bind(id)
        .fetch_optional(&state.pool)
        .await?;
    user.map(Json).ok_or(AppError::NotFound)
}

async fn update_user(
    State(state): State<AppState>,
    Path(id): Path<i64>,
    Json(payload): Json<CreateUser>,
) -> Result<Json<User>, AppError> {
    let user =
        sqlx::query_as::<_, User>("UPDATE users SET name = ? WHERE id = ? RETURNING id, name")
            .bind(&payload.name)
            .bind(id)
            .fetch_optional(&state.pool)
            .await?;
    user.map(Json).ok_or(AppError::NotFound)
}

async fn delete_user(
    State(state): State<AppState>,
    Path(id): Path<i64>,
) -> Result<StatusCode, AppError> {
    let result = sqlx::query("DELETE FROM users WHERE id = ?")
        .bind(id)
        .execute(&state.pool)
        .await?;
    if result.rows_affected() == 0 {
        Err(AppError::NotFound)
    } else {
        Ok(StatusCode::NO_CONTENT)
    }
}

async fn get_user_post(Path((user_id, post_id)): Path<(u32, u32)>) -> String {
    format!("user {user_id} post {post_id}")
}

async fn search(Query(params): Query<HashMap<String, String>>) -> String {
    format!("search params: {params:?}")
}

async fn not_found() -> (StatusCode, &'static str) {
    (StatusCode::NOT_FOUND, "Not Found")
}

use axum::{
    Extension, Json, Router,
    extract::{Path, Query, Request, State, rejection::JsonRejection},
    http::StatusCode,
    middleware::{self, Next},
    response::{IntoResponse, Response},
    routing::{get, post, put},

use serde::{Deserialize, Serialize};
use serde_json::json;
use sqlx::SqlitePool;
use std::collections::HashMap;
use std::time::Instant;

#[derive(Clone, Serialize, sqlx::FromRow)]
struct User {
    id: i64,
    name: String,
}

#[derive(Deserialize)]
struct CreateUser {
    name: String,
}

impl CreateUser {
    fn validate(&self) -> Result<(), AppError> {
        let name = self.name.trim();
        if name.is_empty() {
            return Err(AppError::Validation("name must not be empty".to_string()));
        }
        if name.chars().count() > 50 {
            return Err(AppError::Validation(
                "name must be 50 characters or less".to_string(),
            ));
        }
        Ok(())
    }
}

#[derive(Clone)]
struct AppState {
    pool: SqlitePool,
}

#[derive(Clone)]
struct AppConfig {
    app_name: String,
}

enum AppError {
    NotFound,
    Validation(String),
    Database(sqlx::Error),
    JsonRejection(JsonRejection),
}

impl IntoResponse for AppError {
    fn into_response(self) -> Response {
        let (status, message) = match self {
            AppError::NotFound => (StatusCode::NOT_FOUND, "user not found".to_string()),
            AppError::Validation(message) => (StatusCode::UNPROCESSABLE_ENTITY, message),
            AppError::Database(error) => {
                eprintln!("database error: {error}");
                (
                    StatusCode::INTERNAL_SERVER_ERROR,
                    "internal server error".to_string(),
                )
            }
            AppError::JsonRejection(rejection) => (rejection.status(), rejection.body_text()),
        };
        (status, Json(json!({ "error": message }))).into_response()
    }
}

impl From<sqlx::Error> for AppError {
    fn from(error: sqlx::Error) -> Self {
        AppError::Database(error)
    }
}

impl From<JsonRejection> for AppError {
    fn from(rejection: JsonRejection) -> Self {
        AppError::JsonRejection(rejection)
    }
}

#[tokio::main]
async fn main() {
    let pool = SqlitePool::connect("sqlite://app.db?mode=rwc")
        .await
        .unwrap();

    sqlx::migrate!().run(&pool).await.unwrap();

    let state = AppState { pool };

    let protected_users = Router::new()
        .route("/users", post(create_user))
        .route("/users/{id}", put(update_user).delete(delete_user))
        .route_layer(middleware::from_fn(require_api_key));

    let app = Router::new()
        .route("/", get(root))
        .route("/health", get(health))
        .route("/users", get(list_users))
        .route("/users/{id}", get(get_user))
        .merge(protected_users)
        .route("/users/{user_id}/posts/{post_id}", get(get_user_post))
        .route("/search", get(search))
        .fallback(not_found)
        .layer(Extension(AppConfig {
            app_name: "Handson Axum".to_string(),
        }))
        .layer(middleware::from_fn(log_request))
        .with_state(state);

    let listener = tokio::net::TcpListener::bind("127.0.0.1:3000")
        .await
        .unwrap();
    println!("listening on {}", listener.local_addr().unwrap());
    axum::serve(listener, app).await.unwrap();
}

async fn log_request(req: Request, next: Next) -> Response {
    let method = req.method().clone();
    let uri = req.uri().clone();
    let start = Instant::now();

    let response = next.run(req).await;

    let elapsed = start.elapsed();
    println!("{method} {uri} -> {} ({elapsed:?})", response.status());
    response
}

async fn require_api_key(req: Request, next: Next) -> Response {
    let is_valid = req
        .headers()
        .get("x-api-key")
        .and_then(|value| value.to_str().ok())
        == Some("secret");

    if !is_valid {
        return (StatusCode::UNAUTHORIZED, "invalid or missing x-api-key").into_response();
    }

    next.run(req).await
}

        .fetch_all(&state.pool)
        .await?;
    Ok(Json(users))
}

async fn create_user(
    State(state): State<AppState>,
    payload: Result<Json<CreateUser>, JsonRejection>,

    let Json(payload) = payload?;
    payload.validate()?;

        .await?;

async fn get_user(
    State(state): State<AppState>,
    Path(id): Path<i64>,
) -> Result<Json<User>, AppError> {

        .bind(id)
        .fetch_optional(&state.pool)
        .await?;
    user.map(Json).ok_or(AppError::NotFound)
}

async fn update_user(
    State(state): State<AppState>,
    Path(id): Path<i64>,
    payload: Result<Json<CreateUser>, JsonRejection>,
) -> Result<Json<User>, AppError> {
    let Json(payload) = payload?;
    payload.validate()?;
    let user =
        sqlx::query_as::<_, User>("UPDATE users SET name = ? WHERE id = ? RETURNING id, name")
            .bind(&payload.name)
            .bind(id)
            .fetch_optional(&state.pool)
            .await?;
    user.map(Json).ok_or(AppError::NotFound)
}

async fn delete_user(
    State(state): State<AppState>,
    Path(id): Path<i64>,
) -> Result<StatusCode, AppError> {
    let result = sqlx::query("DELETE FROM users WHERE id = ?")
        .bind(id)
        .execute(&state.pool)
        .await?;
    if result.rows_affected() == 0 {
        Err(AppError::NotFound)
    } else {
        Ok(StatusCode::NO_CONTENT)
    }
}

    format!("user {user_id} post {post_id}")
}

async fn search(Query(params): Query<HashMap<String, String>>) -> String {
    format!("search params: {params:?}")
}

    (
        StatusCode::NOT_FOUND,
        Json(json!({ "error": "route not found" })),
    )
}

演習

以下のチェックリストを使って、このレッスンの内容を振り返りましょう。

つまずきポイント

💡

variant `Validation` is never constructed の警告が出る

ステップ 2〜3 では Validation をまだ使っていないため、この警告が出ます。ステップ 4 で validate から使い始めると消えます。

💡

Handler<_, _> is not satisfied でビルドが失敗する

ハンドラの戻り値のエラー型が IntoResponse を実装しているか確認してください。impl IntoResponse for AppError を消したりコメントアウトしたままにしたりすると、ステップ 7 と同じエラーになります。

💡

空白だけの名前が 422 にならない

validate で trim() を呼んでから is_empty() で判定しているか確認してください（ステップ 4 を参照）。

💡

415・400・422 の本文が JSON にならない

ハンドラの引数が Json(payload): Json<CreateUser> のままになっていないか確認してください。Result<Json<CreateUser>, JsonRejection> で受け取らないと、axum が text/plain の本文で拒否します（ステップ 5 を参照）。

💡

コードを変えたのに結果が変わらない

cargo run で起動したサーバーは、ソースコードを保存しても変更を反映しません。各ステップでコードを変えたら、前のサーバーを Ctrl + C で止めてから cargo run し直してください。止め忘れたまま別のターミナルで起動すると、ポート 3000 が使用中のエラーになります（01 の「つまずきポイント」を参照）。

まとめ

独自のエラー型 AppError に IntoResponse を実装し、ハンドラが返すエラーの応答を {"error": "..."} という JSON にそろえました。 From を実装したことで、DB のエラーも JSON の拒否も ? だけで AppError に変換でき、ハンドラから map_err がなくなりました。 入力値の検証は validate メソッドにまとめ、不正な値は DB へアクセスする前に 422 で返します。 最終的な AppError とレスポンスの対応は次のとおりです。

variant作られる場所ステータス本文の error
NotFoundget_user・update_user・delete_user で対象がないとき404user not found
Validation(String)CreateUser::validate422検証で失敗した理由
Database(sqlx::Error)sqlx のエラーから ?（From）で変換500internal server error（詳細はサーバー側に出力）
JsonRejection(JsonRejection)Json extractor の拒否から ?（From）で変換rejection.status()（415 / 400 / 422）rejection.body_text()
