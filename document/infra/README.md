# Infra トラック

Terraform を使ったインフラ構築を、各クラウドプロバイダーごとに学ぶトラックです。`terraform/` はクラウド非依存の基礎操作、それ以外（`google-cloud/` `aws/` `azure/` `cloudflare/`）は各クラウドでの構築を扱います。

## カリキュラム表

進捗は Obsidian の Projects/handson/progress.md で管理する。

### Terraform（`terraform/`）

| 番号 | タイトル | 到達目標 | 所要時間 |
| --- | --- | --- | --- |
| 01 | Terraform の基本操作 | `init` / `plan` / `apply` の流れと state の概念を理解する | 30分 |
| 02 | 変数とアウトプット | variables / outputs でモジュール間の値をやり取りできる | 30分 |
| 03 | モジュール化 | 再利用可能なモジュールを作成し呼び出せる | 45分 |
| 04 | リモートステート管理 | リモートバックエンドで state を共有管理できる | 45分 |
