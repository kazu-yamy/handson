# Tauri トラック

Rust 製のデスクトップアプリフレームワーク Tauri を使ったアプリ開発を学ぶトラックです。フロントエンドは Next.js の静的（SPA）出力を使用します。

## カリキュラム表

進捗は Obsidian の Projects/handson/progress.md で管理する。

| 番号 | タイトル | 到達目標 | 所要時間 |
| --- | --- | --- | --- |
| 01 | [環境構築とプロジェクト作成](./01-setup/index.html) | Tauri CLI のセットアップと Next.js SPA 出力の組み込みができる | 45分 |
| 02 | ウィンドウ設定とビルド | `tauri.conf` でウィンドウ設定を行い、デスクトップアプリとしてビルドできる | 30分 |
| 03 | Rust コマンドの呼び出し | `invoke` でフロントエンドから Rust コマンドを呼び出せる | 45分 |
| 04 | ファイルシステム API の利用 | Tauri のファイルシステム / ダイアログ API を使える | 45分 |
| 05 | パッケージングと配布 | 各 OS 向けにアプリをパッケージングできる | 45分 |
