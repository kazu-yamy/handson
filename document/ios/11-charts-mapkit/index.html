Charts と MapKit

  • ⏱ 所要時間: 60分
  • 📊 難易度: 中級
  • 👤 対象: SwiftData で保存する ToDo アプリを作ったことがあり、その内容をグラフと地図で見せたい人
  • 📋 前提: 10 でウィジェットとショートカットを加えた HandsonApp プロジェクトが手元にあること。SwiftData の @Model・@Query・ModelContext と、Swift Testing の @Test・#expect を使ったことがあること
  • 🔗 前提となる項目: 10 WidgetKit と App Intents

🎯 このレッスンで学ぶこと

  • 集計の処理を画面から分けた型にし、ユニットテストで確かめる
  • Swift Charts の Chart と BarMark で棒グラフを描く
  • annotation・軸・凡例・色の指定でグラフを整え、SectorMark でドーナツグラフを描く
  • SwiftData のモデルに省略可能なプロパティを足し、既存のデータのまま開けること（軽量マイグレーション）を確かめる
  • MapKit の Map と Marker で地図とピンを表示する
  • MapReader で、地図をタップした位置を緯度経度に変換して保存する

概要

10 までの ToDo アプリに、2 つの画面要素を加えます。1 つ目は、完了と未完了の件数を表す統計画面です。Swift Charts で棒グラフとドーナツグラフを描きます。 2 つ目は、ToDo の詳細画面の地図です。地図をタップすると、その場所を ToDo に保存できます。

Swift Charts と MapKit は SDK に含まれているので、追加のパッケージは要りません。完成すると、ユニットテストは 76 から 82 に、UI テストは 2 から 3 に増えます。

ℹ️

使用バージョンと並行処理の設定

Xcode 27.0 / Swift 6.4（Swift 6 言語モード）/ 最小対象 iOS 18.0 / シミュレータ iPhone 17（iOS 27.0）は 10 と同じです。バージョンは執筆時点（2026年10月）のものです。

アプリターゲットは 10 と同じく、SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor です。アプリの型は既定でメインアクターに分離されます。テストから使うときにこの設定が効いてきます（ステップ 1）。

この項目では現在地を取得しません（現在地を取得する Core Location の位置情報サービスは使いません）。そのため、位置情報の利用を許可するダイアログは出ません。ただし、地図のタイル（地図の画像）を表示するには、シミュレータを動かす Mac がネットワークにつながっている必要があります。

手順

1

集計の型 TodoStats を作ってテストする

グラフを描く前に、表示する数（完了と未完了の件数）を数える型を作ります。画面やグラフから切り離した型にしておくと、ユニットテストで確かめられます。 HandsonApp/Models フォルダに TodoStats.swift を追加します（Targets は HandsonApp）。

Swift HandsonApp/Models/TodoStats.swift（ステップ 1 の版） 
import Foundation

// 完了 / 未完了の件数を数える。画面にもグラフにも依存しない純粋な型
struct TodoStats: Equatable {
    let done: Int
    let pending: Int

    var total: Int { done + pending }

    init(records: [TodoRecord]) {
        done = records.filter(\.isDone).count
        pending = records.count - done
    }
}
  • init(records:) は TodoRecord の配列を受け取り、isDone が true のものを完了として数えます。残りが未完了です。
  • Equatable に準拠させているので、テストで == を使って比べられます。

テストを書きます。HandsonAppTests フォルダに TodoStatsTests.swift を追加します（Targets は HandsonAppTests）。

Swift HandsonAppTests/TodoStatsTests.swift 
import Testing
@testable import HandsonApp

@MainActor
struct TodoStatsTests {
    @Test func 完了と未完了の件数を数える() {
        let finished = TodoRecord(title: "完了")
        finished.toggle()
        let records = [finished, TodoRecord(title: "未完了A"), TodoRecord(title: "未完了B")]

        let stats = TodoStats(records: records)

        #expect(stats.done == 1)
        #expect(stats.pending == 2)
        #expect(stats.total == 3)
    }

    @Test func 空の配列ならすべて0() {
        let stats = TodoStats(records: [])
        #expect(stats == TodoStats(records: []))
        #expect(stats.total == 0)
    }
}
⚠️

2

Chart と BarMark で棒グラフを描き、統計画面へ遷移する

Swift Charts の Chart は、データの配列を受け取り、要素ごとに「マーク」（棒や点など、グラフを形作る図形）を描きます。Chart(stats.entries) { … } のように配列を渡す書き方では、配列の要素を Identifiable にします。 そこで、TodoStats に 1 本の棒に当たるデータ型 Entry を加えます。total の下に追加します。

統計画面を作ります。HandsonApp/Views フォルダに TodoStatsView.swift を追加します（Targets は HandsonApp）。

Swift HandsonApp/Views/TodoStatsView.swift（ステップ 2 の版） 
import Charts
import SwiftData
import SwiftUI

struct TodoStatsView: View {
    @Query private var records: [TodoRecord]

    private var stats: TodoStats { TodoStats(records: records) }

    var body: some View {
        List {
            Section("件数") {
                Chart(stats.entries) { entry in
                    BarMark(
                        x: .value("状態", entry.status),
                        y: .value("件数", entry.count)
                    )
                    // 状態ごとに色を分ける（凡例も自動で付く）
                    .foregroundStyle(by: .value("状態", entry.status))
                }
                .frame(height: 220)
            }
        }
        .navigationTitle("統計")
        .navigationBarTitleDisplayMode(.inline)
    }
}

  • @Query で全ての TodoRecord を読み、TodoStats で数えます。ToDo が増減すると、@Query の結果が変わり、グラフも描き直されます。
  • BarMark が棒 1 本です。.value("状態", entry.status) のように、軸の名前と値の組で X と Y を指定します。
  • .foregroundStyle(by:) は、値ごとに色を分けます。色を分けると、凡例も自動で付きます。

3

注釈・軸・凡例を整え、SectorMark でドーナツグラフを加える

棒グラフを見やすく整え、割合を表すドーナツグラフを加えます。TodoStatsView.swift を次の全文に置き換えます。

Swift HandsonApp/Views/TodoStatsView.swift 
import Charts
import SwiftData
import SwiftUI

struct TodoStatsView: View {
    @Query private var records: [TodoRecord]

    private var stats: TodoStats { TodoStats(records: records) }

    // 状態と色の対応を 1 か所で決める（2 つのグラフで同じ色にそろえる）
    private let colors: KeyValuePairs<String, Color> = ["完了": .green, "未完了": .orange]

    var body: some View {
        List {
            Section("件数") {
                Chart(stats.entries) { entry in
                    BarMark(
                        x: .value("状態", entry.status),
                        y: .value("件数", entry.count)
                    )
                    .foregroundStyle(by: .value("状態", entry.status))
                    // 棒の上に件数を表示する
                    .annotation(position: .top) {
                        Text("\(entry.count)")
                            .font(.caption.bold())
                    }
                    .accessibilityLabel(entry.status)
                    .accessibilityValue("\(entry.count) 件")
                }
                .chartForegroundStyleScale(colors)
                // 件数は小さい整数なので、目盛りの数を 3 程度に抑える
                .chartYAxis {
                    AxisMarks(values: .automatic(desiredCount: 3)) { _ in
                        AxisGridLine()
                        AxisValueLabel()
                    }
                }
                // X 軸は凡例と重複するので隠す
                .chartXAxis(.hidden)
                .chartLegend(position: .bottom, alignment: .center)
                .frame(height: 220)
            }

            Section("割合") {
                Chart(stats.entries) { entry in
                    SectorMark(
                        angle: .value("件数", entry.count),
                        innerRadius: .ratio(0.6),  // 内側をくり抜いてドーナツにする
                        angularInset: 2
                    )
                    .foregroundStyle(by: .value("状態", entry.status))
                    .accessibilityLabel(entry.status)
                    .accessibilityValue("\(entry.count) 件")
                }
                .chartForegroundStyleScale(colors)
                .chartBackground { _ in
                    // ドーナツの中央に合計を出す
                    VStack {
                        Text("\(stats.total)")
                            .font(.title.bold())
                        Text("件")
                            .font(.caption)
                            .foregroundStyle(.secondary)
                    }
                }
                .chartLegend(position: .bottom, alignment: .center)
                .frame(height: 240)
            }
        }
        .navigationTitle("統計")
        .navigationBarTitleDisplayMode(.inline)
    }
}

#Preview {
    NavigationStack { TodoStatsView() }
        .modelContainer(for: TodoRecord.self, inMemory: true)
}

ステップ 2 からの変更点は次のとおりです。

  • chartForegroundStyleScale: 値と色の対応を決めます。foregroundStyle(by:) だけでは、既定の配色になります。対応を colors の 1 か所で決め、2 つのグラフに同じものを渡して色をそろえます。
  • annotation(position: .top): 棒の上に件数を表示します。
  • chartYAxis: AxisMarks(values: .automatic(desiredCount: 3)) で、目盛りの数の目安を 3 にします。AxisGridLine() が目盛りの線、AxisValueLabel() が目盛りの数値です。
  • chartXAxis(.hidden): X 軸のラベルは凡例と同じ内容なので隠します。chartLegend(position: .bottom, alignment: .center) で、凡例をグラフの下の中央に置きます。
  • SectorMark: 扇形のマークです。angle に件数を渡すと、件数の割合で円を分けます。innerRadius: .ratio(0.6) で内側をくり抜いてドーナツにし、angularInset: 2 で扇形の間に隙間を空けます。
  • chartBackground: グラフの背景にビューを置きます。ここではドーナツの中央に合計の件数を出します。クロージャーはグラフの情報（ChartProxy）を受け取りますが、今回は使わないので _ にしています。
  • accessibilityLabel / accessibilityValue: マークごとに、VoiceOver に伝える名前（状態）と値（件数）を付けます。

ビルドしてアプリを実行し、ステップ 2 と同じく完了 1 件・未完了 2 件の状態で「統計」画面を開きます。

✅ 確認ポイント

「件数」のグラフで、緑（完了）の棒の上に「1」、橙（未完了）の棒の上に「2」が表示されることを確かめます。X 軸のラベルは消え、凡例（緑が完了、橙が未完了）が下の中央に出ます。執筆時、Y 軸の目盛りは右側に 0 / 2 / 4 でした。

「割合」のグラフは、橙が約 3 分の 2、緑が約 3 分の 1 のドーナツになり、中央に「3」「件」が表示されます。扇形の間には細い隙間があります。

ToDo が 0 件のときは、ドーナツと Y 軸の目盛りが消え、中央の「0」「件」と、棒グラフ領域の中ほどに浮いた注釈「0」「0」、凡例だけが表示されました。VoiceOver での実際の読み上げは、執筆時に確かめていません。

モデルに緯度と経度を足し、既存のデータのまま開けることを確かめる

ここから地図の機能に移ります。まず、ToDo に場所を持たせます。TodoRecord.swift の createdAt の下に緯度と経度のプロパティを、init と toggle() の間に hasLocation を追加します。init は変えません。

  • 新しい 2 つのプロパティは省略可能（Double?）で、初期値は nil です。そのため、init で代入しなくても済みます。
  • 保存済みのデータベースには、この 2 つの列がありません。省略可能なプロパティを足しただけなら、SwiftData が既存のデータを nil のまま読み込めるよう、自動で移行します（軽量マイグレーション）。VersionedSchema や SchemaMigrationPlan は書きません。
ℹ️

座標型ではなく、Double を 2 つ持たせる理由

TodoRecord.swift は、10 からウィジェットの拡張（TodoWidgetExtension）にも入れています。モデルに座標型（Core Location の CLLocationCoordinate2D）を持たせると、ウィジェットにも位置情報のフレームワークを読み込ませることになります。 そこで、モデルには Double を 2 つだけ持たせ、座標型への変換は地図を表示する画面で行います（ステップ 5）。

ウィジェットの拡張もビルドできることを確かめます。

5

Map・Marker・MapReader で、地図をタップして場所を設定する

詳細画面に地図を置きます。場所があればピン（Marker）を立て、地図をタップすると、その位置を ToDo の場所として保存します。 まず、場所を設定する・消すメソッドを TodoRecord に加えます。hasLocation の下に追加します。

Diff HandsonApp/Models/TodoRecord.swift

TodoDetailView.swift を次の全文に置き換えます。10 までの 4 行（タイトル・優先度・状態・完了日時）はそのままで、import・init・「場所」の Section・プレビューを加えています。

Swift HandsonApp/Views/TodoDetailView.swift 
import MapKit
import SwiftData
import SwiftUI

struct TodoDetailView: View {
    // 保存を明示的に行うための窓口
    @Environment(\.modelContext) private var modelContext
    let record: TodoRecord

    // 地図の表示位置。初期値は場所があればそこ
    @State private var position: MapCameraPosition

    init(record: TodoRecord) {
        self.record = record
        if let latitude = record.latitude, let longitude = record.longitude {
            let center = CLLocationCoordinate2D(latitude: latitude, longitude: longitude)
            _position = State(initialValue: .region(
                MKCoordinateRegion(center: center, latitudinalMeters: 1000, longitudinalMeters: 1000)
            ))
        } else {
            // 場所が無いときは東京駅あたりを中心にしておく
            let tokyo = CLLocationCoordinate2D(latitude: 35.681236, longitude: 139.767125)
            _position = State(initialValue: .region(
                MKCoordinateRegion(center: tokyo, latitudinalMeters: 5000, longitudinalMeters: 5000)
            ))
        }
    }

    // 緯度と経度がそろっているときだけ座標になる
    private var coordinate: CLLocationCoordinate2D? {
        guard let latitude = record.latitude, let longitude = record.longitude else { return nil }
        return CLLocationCoordinate2D(latitude: latitude, longitude: longitude)
    }

    var body: some View {
        List {
            LabeledContent("タイトル", value: record.title)
            LabeledContent("優先度", value: record.priority.label)
            LabeledContent("状態", value: record.isDone ? "完了" : "未完了")
            if let date = record.completedAt {
                LabeledContent("完了日時") {
                    Text(date, format: .dateTime.year().month().day().hour().minute())
                }
            }

            Section {
                MapReader { proxy in
                    Map(position: $position) {
                        if let coordinate {
                            Marker(record.title, coordinate: coordinate)
                        }
                    }
                    // タップした画面上の位置（ローカル座標）を、地図上の緯度経度に変換する
                    .onTapGesture { point in
                        if let tapped = proxy.convert(point, from: .local) {
                            record.setLocation(latitude: tapped.latitude, longitude: tapped.longitude)
                            // 自動保存を待たず、設定の直後に保存する
                            try? modelContext.save()
                        }
                    }
                }
                .frame(height: 280)

                if let coordinate {
                    Text("緯度 \(coordinate.latitude, specifier: "%.4f") / 経度 \(coordinate.longitude, specifier: "%.4f")")
                        .foregroundStyle(.secondary)
                    Button("場所を消す", role: .destructive) {
                        record.clearLocation()
                        try? modelContext.save()
                    }
                } else {
                    Text("地図をタップして場所を設定")
                        .foregroundStyle(.secondary)
                }
            } header: {
                Text("場所")
            }
        }
        .navigationTitle(record.title)
        .navigationBarTitleDisplayMode(.inline)
    }

  • MapCameraPosition: 地図のどこを、どの広さで表示するかです。@State に持たせ、Map(position: $position) にバインディングで渡します。init で、場所があればそこを中心に 1km 四方、無ければ東京駅のあたりを中心に 5km 四方を初期値にします。
  • Map { … } と Marker: Map のクロージャーに、地図に重ねるもの（コンテンツ）を書きます。Marker は、タイトル付きのピンです。場所がある（coordinate が nil でない）ときだけ置きます。
  • MapReader と proxy.convert(_:from:): MapReader の中に Map を置くと、MapProxy（proxy）を受け取れます。.onTapGesture で受け取る point は、Map 自身の座標系での画面上の位置です。そのため、proxy.convert(point, from: .local) で緯度経度に変換します。変換できない位置では nil が返るので、if let で受けます。
  • 場所を設定・削除した直後に try? modelContext.save() を呼びます。一覧画面の追加・削除と同じく、自動保存を待たずに保存します。
  • 場所はウィジェットに表示しないので、10 で入れた WidgetCenter.shared.reloadAllTimelines() は呼びません。
  • 場所が無いときも地図は常に表示し、下に「地図をタップして場所を設定」と出します。場所があるときは、緯度経度（小数点以下 4 桁）と「場所を消す」ボタンを出します。

場所のテストを加え、完成状態を確かめる

場所を扱うメソッドと、保存して読み直したときに場所が残ることをテストします。HandsonAppTests フォルダに TodoLocationTests.swift を追加します（Targets は HandsonAppTests）。

    }

  • 保存して取得し直しても場所が残る は、メモリ上のコンテナ（isStoredInMemoryOnly: true）に保存して取得し直します。追加したプロパティが SwiftData に保存されることを確かめます。

演習

以下のチェックリストを使って、このレッスンの内容を振り返りましょう。

つまずきポイント

💡

グラフの色が指定した色にならない

foregroundStyle(by:) だけでは、システムの既定の配色（執筆時は青と緑）になります。chartForegroundStyleScale に値と色の対応を渡しているかを確かめてください（ステップ 3）。

💡

地図が表示されない、タップしても場所が設定されない

地図のタイルの表示には、ネットワーク接続が要ります。タップで場所が設定されないときは、2 点を確かめてください。Map を MapReader の中に置いているか、proxy.convert(point, from: .local) のように .local を渡しているかです。.onTapGesture の point は Map 自身の座標系での位置です。

💡

新しいファイルで「not available due to missing import」と出る

MemberImportVisibility が有効なので、使うフレームワークはファイルごとに import します。この項目の完成コードでは、TodoStatsView.swift が Charts・SwiftData・SwiftUI を import しています。TodoDetailView.swift は MapKit・SwiftData・SwiftUI です。

まとめ

完了と未完了の件数を数える処理を TodoStats に分けてテストし、Swift Charts の BarMark で棒グラフ、SectorMark でドーナツグラフを描きました。色は chartForegroundStyleScale で 1 か所にまとめ、注釈・軸・凡例を整えました。 モデルには省略可能な緯度と経度を足し、10 で保存したデータがそのまま開けることを確かめました。ウィジェットとモデルを共有しているので、座標型は持たせていません。 詳細画面では Map と Marker で地図とピンを表示し、MapReader でタップした位置を緯度経度に変換して保存しました。 次の項目では、TestFlight でアプリを配布します。
