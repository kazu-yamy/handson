概要

02 で作った Profile と TodoItem を、SwiftUI の画面に表示します。 完成すると、画面の上部にプロフィールのカード、その下に 3 件の ToDo が並びます。 ボタンやタップによる状態の変更は扱わず、「データを受け取って表示する View」を組み立てることに集中します。状態の変更は次の 04 で扱います。

02 と同じく、Xcode の画面での操作と、同じ結果をターミナルで確かめるコマンドの両方を載せています。どちらか一方で進めてかまいません。 ターミナルで進める場合は、ビルドした .app をシミュレータにインストールして画面を確かめます。

2

Text と修飾子で見た目を整える

ContentView.swift を開きます。今は 01 で書いた、地球のアイコンと Hello, SwiftUI! を縦に並べる画面のままです。

Swift HandsonApp/ContentView.swift（変更前） 
struct ContentView: View {
    var body: some View {
        VStack {
            Image(systemName: "globe")
                .imageScale(.large)
                .foregroundStyle(.tint)
            Text("Hello, SwiftUI!")
                .font(.title)
        }
        .padding()
    }
}

SwiftUI の画面は、View プロトコルに準拠した構造体で作ります。body プロパティに、画面に表示する View を書きます。 Text("…") は文字列を表示する View で、後ろに .font(.title) のように続けて書くメソッドを修飾子（modifier）と呼びます。 ファイル全体を次の内容に書き換えます。

Swift HandsonApp/ContentView.swift 
//
//  ContentView.swift
//  HandsonApp
//

import SwiftUI

struct ContentView: View {
    var body: some View {
        VStack {
            Text("Handson Profile")
                .font(.title)
                .fontWeight(.bold)
                .foregroundStyle(.secondary)
                .padding()

            // 修飾子の順序: padding → background（余白も含めて色が付く）
            Text("padding → background")
                .padding()
                .background(.yellow)

            // background → padding（文字の範囲だけに色が付く）
            Text("background → padding")
                .background(.yellow)
                .padding()
        }
    }
}

#Preview {
    ContentView()
}
  • .font(.title)・.fontWeight(.bold): 文字の大きさと太さを指定します。
  • .foregroundStyle(.secondary): 文字の色を指定します。.secondary は控えめな灰色の文字になります。色の指定には .foregroundColor ではなく、新しい API の .foregroundStyle を使います。
  • .padding(): View の周りに余白を付けます。
  • .background(.yellow): View の背景に色を付けます。

下の 2 つの Text は、.padding() と .background(.yellow) を逆の順序で付けています。 修飾子は上から順に「それまでの結果を包む」ように適用されます。そのため、順序によって次のように見た目が変わります。

  • .padding() → .background(.yellow): 先に余白を付けた View 全体に背景を付けるので、余白ごと黄色になります。
  • .background(.yellow) → .padding(): 文字だけに背景を付けてから余白を足すので、黄色は文字の範囲だけで、余白は外側に付きます。
💡

順序で結果が変わる修飾子・変わらない修飾子

順序で結果が変わるのは、padding・frame・background・border のようにレイアウトや範囲に関わる修飾子です。 1 つ目の Text の .foregroundStyle(.secondary) を .font より前に書いても、見た目は同じです。

ビルドしてシミュレータで確かめます。シミュレータを起動し、ビルドした .app をインストールして起動します。

Terminal

Xcode では、コードを書きながらキャンバス（Canvas）で画面を確かめられます。#Preview { … } がキャンバスに表示する内容です。 メニューの Editor > Canvas（⌥ + ⌘ + ↩）でキャンバスを表示し、表示が止まっている場合は右上の Resume（⌥ + ⌘ + P）で再描画します。 キャンバス上の Text を ⌘ + クリックして Show SwiftUI Inspector を選ぶと、フォントや色を画面から変更でき、コードも書き換わります。

✅ 確認ポイント

画面の中央に、上から順に次の 3 つが並びます。 灰色の太字で「Handson Profile」、余白ごと黄色い四角に収まった「padding → background」、文字の範囲だけが黄色い「background → padding」です。 2 つの黄色の大きさが違うことで、修飾子の順序で結果が変わることを確認してください。

3

スタックでプロフィールのカードを組み立てる

02 で作った Profile を使い、アイコン・名前・星を並べたカードを作ります。 View を縦に並べる VStack、横に並べる HStack、空いた場所を埋める Spacer を組み合わせます。 ContentView.swift を次の内容に書き換えます。

Swift HandsonApp/ContentView.swift 
//
//  ContentView.swift
//  HandsonApp
//

import SwiftUI

struct ContentView: View {
    let profile = Profile(name: "Taro Yamada", nickname: "Taro")

    var body: some View {
        VStack(alignment: .leading, spacing: 16) {
            HStack(spacing: 12) {
                Image(systemName: "person.crop.circle.fill")
                    .font(.system(size: 48))
                    .foregroundStyle(.tint)
                VStack(alignment: .leading, spacing: 4) {
                    Text(profile.displayName)
                        .font(.title2)
                        .fontWeight(.bold)
                    Text(profile.name)
                        .font(.subheadline)
                        .foregroundStyle(.secondary)
                }
                Spacer()
                Image(systemName: "star.fill")
                    .foregroundStyle(.yellow)
            }
            .padding()
            .frame(maxWidth: .infinity)
            .background(.quaternary, in: RoundedRectangle(cornerRadius: 12))

            Spacer()
        }
        .padding()
    }
}

#Preview {
    ContentView()
}
  • Image(systemName: "person.crop.circle.fill"): SF Symbols のアイコンを名前で表示します。.font(.system(size: 48)) で大きさを、.foregroundStyle(.tint) でアプリのアクセントカラー（青）を指定しています。
  • VStack(alignment: .leading, spacing: 4): alignment は子の揃え方、spacing は子どうしの間隔です。VStack の alignment は横方向の揃え（.leading は左揃え）で、HStack の alignment は縦方向の揃え（.top・.center・.bottom）です。
  • Spacer(): 残りの空間を全て取ります。HStack の中では星を右端に押し出し、外側の VStack の末尾ではカードを画面の上に押し上げます。
  • .frame(maxWidth: .infinity): カードを横幅いっぱいに広げます。.background より前に置いているので、背景も横幅いっぱいに付きます。ステップ 2 の修飾子の順序と同じ考え方です。
  • .background(.quaternary, in: RoundedRectangle(cornerRadius: 12)): 角丸の四角形の形で、薄い灰色の背景を付けます。

let profile = Profile(…) のように、View の中に表示するデータを持たせられます。 Text(profile.displayName) には、02 で書いた displayName（ニックネームがあればニックネーム）が表示されます。

ℹ️

Xcode でスタックに包む

キャンバスやエディタで View を ⌘ + クリックし、Embed in HStack や Embed in VStack を選ぶと、選んだ View をスタックで包むコードに書き換えられます。

ビルドしてシミュレータに入れ直します。install で新しい .app に置き換えてから launch します。

✅ 確認ポイント

画面の上部に、角丸で薄い灰色のカードが横幅いっぱいに表示されます。 カードの左に青い丸の人型アイコン、その右に太字の「Taro」と灰色の小さな「Taro Yamada」、右端に黄色い星が並びます。 カードの下は空白で、全体が上に詰まっていれば OK です。

4

カードをサブビューに切り出してプレビューする（ProfileHeader）

body が長くなってきたので、カードの部分を ProfileHeader という別の View に切り出します。 表示する Profile は引数で受け取るようにし、ニックネームの有無で表示を変えます。まず、Xcode でフォルダとファイルを作ります。

  1. ナビゲータで HandsonApp フォルダ（黄色）を右クリックし、New Group（または New Folder）で Views を作ります。
  2. Views を右クリックし、New File from Template…（⌘ + N）を選びます。iOS > SwiftUI View を選び、名前を ProfileHeader、Targets は HandsonApp にチェックを付けて作成します。テンプレートには #Preview があらかじめ書かれています。

02 と同じく HandsonApp は同期フォルダなので、HandsonApp/Views/ProfileHeader.swift にファイルを置くだけでもターゲットに取り込まれます。ターミナルで進める場合は、プロジェクトのフォルダで mkdir HandsonApp/Views を実行してフォルダを作ります。中身を次の内容にします。

Swift HandsonApp/Views/ProfileHeader.swift 
import SwiftUI

struct ProfileHeader: View {
    let profile: Profile

    var body: some View {
        HStack(spacing: 12) {
            Image(systemName: "person.crop.circle.fill")
                .font(.system(size: 48))
                .foregroundStyle(.tint)
            VStack(alignment: .leading, spacing: 4) {
                Text(profile.displayName)
                    .font(.title2)
                    .fontWeight(.bold)
                // ニックネームがあるときだけ本名を添える
                if profile.nickname != nil {
                    Text(profile.name)
                        .font(.subheadline)
                        .foregroundStyle(.secondary)
                }
            }
            Spacer()
        }
        .padding()
        .frame(maxWidth: .infinity)
        .background(.quaternary, in: RoundedRectangle(cornerRadius: 12))
    }
}

#Preview("ニックネームあり") {
    ProfileHeader(profile: Profile(name: "Taro Yamada", nickname: "Taro"))
        .padding()
}

#Preview("ニックネームなし") {
    ProfileHeader(profile: Profile(name: "Hanako Suzuki", nickname: nil))
        .padding()
}
  • let profile: Profile: 表示するデータをプロパティで受け取ります。構造体なので、ProfileHeader(profile:) のイニシャライザが自動で用意されます。
  • if profile.nickname != nil { … }: body の中では if で表示する View を切り替えられます。ニックネームが無いときは 2 行目の本名を表示しません（1 行目の displayName がすでに本名になるため）。
  • ステップ 3 にあった星（star.fill）は、ここでは外しています。
  • #Preview("ニックネームあり") { … }: #Preview は 1 つのファイルに複数書けます。括弧内の文字列がプレビューの名前になり、引数を変えた複数のパターンを並べて確かめられます。中の .padding() は、プレビューでカードが画面の端に貼り付かないようにするためだけのものです。

5

ForEach と switch で ToDo の一覧を表示する（TodoRow）

02 で作った TodoItem を 1 行で表示する TodoRow を作り、ForEach で 3 件並べます。 Views フォルダに SwiftUI View のファイル TodoRow.swift を作り、次の内容を書きます。Views フォルダはステップ 4 で作成済みなので、mkdir は不要です。

Swift HandsonApp/Views/TodoRow.swift 
import SwiftUI

struct TodoRow: View {
    let item: TodoItem

    var body: some View {
        HStack(spacing: 12) {
            // switch: Status の case ごとにアイコンを切り替える
            switch item.status {
            case .todo:
                Image(systemName: "circle")
                    .foregroundStyle(.secondary)
            case .done:
                Image(systemName: "checkmark.circle.fill")
                    .foregroundStyle(.green)
            }

            Text(item.title)
                .strikethrough(isDone)

            Spacer()

            Text(item.priority.label)
                .font(.caption)
                .padding(.horizontal, 8)
                .padding(.vertical, 2)
                .background(.quaternary, in: Capsule())
        }
    }

    private var isDone: Bool {
        if case .done = item.status {
            return true
        }
        return false
    }
}

#Preview("未完了") {
    TodoRow(item: TodoItem(title: "牛乳を買う", priority: .high))
        .padding()
}

#Preview("完了") {
    TodoRow(item: TodoItem(title: "メールを返す", priority: .low, status: .done(Date())))
        .padding()
}
  • switch item.status { … }: body の中では switch でも表示する View を切り替えられます。未完了は灰色の丸、完了は緑のチェックマークにしています。case .done: のように書くと、関連値（完了日時）は無視できます。
  • .strikethrough(isDone): 引数が true のときだけ文字に取り消し線を引きます。
  • private var isDone: Bool: Status は Equatable に準拠していないため == で比べられません。そこで if case .done = item.status で完了かどうかを判定しています。
  • .background(.quaternary, in: Capsule()): 優先度のラベルを、薄い灰色のカプセル形で囲みます。
ℹ️

body では return が要らず、isDone では要る理由

body は ViewBuilder という仕組みで組み立てられるため、View を並べたり、if・switch で切り替えたりするだけで、return を書かずに View を返せます。 Xcode 27 のクイックヘルプでは @ContentBuilder と表示されますが、これは ViewBuilder の別名です。 一方、isDone のような通常のプロパティの中は ViewBuilder ではないため、return true のように値を返す必要があります。

ContentView.swift に ToDo のデータと一覧を追加します。

Swift HandsonApp/ContentView.swift 
//
//  ContentView.swift
//  HandsonApp
//

import SwiftUI

struct ContentView: View {
    let profile = Profile(name: "Taro Yamada", nickname: "Taro")

    let items: [TodoItem] = [
        TodoItem(title: "牛乳を買う", priority: .high),
        TodoItem(title: "メールを返す", priority: .low, status: .done(Date())),
        TodoItem(title: "SwiftUI を勉強する"),
    ]

    var body: some View {
        VStack(alignment: .leading, spacing: 16) {
            ProfileHeader(profile: profile)

            Text("Todo")
                .font(.headline)

            // List は 05 で扱う。ここでは ForEach を VStack に並べる
            VStack(alignment: .leading, spacing: 12) {
                ForEach(items, id: \.title) { item in
                    TodoRow(item: item)
                }
            }

            if items.isEmpty {
                Text("Todo はありません")
                    .foregroundStyle(.secondary)
            }

            Spacer()
        }
        .padding()
    }
}

#Preview {
    ContentView()
}
  • ForEach(items, id: \.title) { item in … }: 配列の要素ごとに View を作ります。id: には、各要素を区別するためのプロパティをキーパスで指定します。TodoItem は Identifiable に準拠していないため、ここでは title を ID にしています。
  • if items.isEmpty { … }: 配列が空のときだけ「Todo はありません」を表示します。今は 3 件あるため表示されません。
  • 3 件目の TodoItem(title: "SwiftUI を勉強する") は優先度を省略しているため、02 で決めた既定値 .medium（中）になります。
⚠️

タイトルを ID にすると重複に弱い

id: \.title では、同じタイトルの ToDo が 2 件あると ID が衝突します。この項目ではタイトルが全て異なるので問題ありませんが、実際のアプリでは各要素に一意な ID を持たせます。

試しに 4 件目として同じタイトルの TodoItem(title: "牛乳を買う", priority: .low) を追加しても、ビルドは通ります。実行すると、Xcode のコンソールに次の警告が出ます。

ForEach<Array<TodoItem>, String, TodoRow>: the ID 牛乳を買う occurs multiple times within the collection, this will give undefined results!

このとき、SwiftUI が別の行の内容を表示してしまうことがあります。実測では、優先度 .low の行に「高」と表示されました。

Xcode では TodoRow.swift のキャンバスで「未完了」「完了」の 2 つのプレビューを切り替えられます。 「未完了」は灰色の丸と「牛乳を買う」と「高」、「完了」は緑のチェックマークと取り消し線付きの「メールを返す」と「低」が表示されます。

上部にプロフィールのカード、その下に見出し「Todo」、さらに 3 行の ToDo が並びます。 1 行目は灰色の丸と「牛乳を買う」で右端に「高」、2 行目は緑のチェックマークと取り消し線付きの「メールを返す」で右端に「低」、3 行目は灰色の丸と「SwiftUI を勉強する」で右端に「中」です。 右端の優先度は、薄い灰色のカプセルで囲まれています。「Todo はありません」は表示されません。

6

body に書けないものを確かめる

ステップ 5 で見たとおり、body は ViewBuilder で組み立てられます。何が書けて何が書けないかを、実験用のファイルで確かめます。 Views フォルダに Fail6a1.swift を作り、次の内容を書きます。このファイルは確認後に削除します。

Swift HandsonApp/Views/Fail6a1.swift（実験用。確認後に削除する） 
import SwiftUI

struct Fail6a1: View {
    var body: some View {
        Text("一つ目")
        Text("二つ目")
    }
}
Terminal 
$ xcodebuild -project HandsonApp.xcodeproj -scheme HandsonApp -destination 'platform=iOS Simulator,name=iPhone 17' -derivedDataPath $DD build…** BUILD SUCCEEDED **
ℹ️

Text を 2 つ並べるだけならビルドは通る

VStack などで包まずに Text を 2 つ並べても、ビルドは成功します。body は ViewBuilder なので、複数の子を返せるためです（内部では TupleView になります）。 ただし、縦に並ぶか横に並ぶかはこの View を使う側の文脈で決まり、この View だけでは決まりません。並べ方を明確にするため、通常は VStack などのコンテナで明示的に包みます。

次に、body を次のように書き換えて、View ではない文を混ぜてみます。

Swift HandsonApp/Views/Fail6a1.swift（実験用。確認後に削除する） 
import SwiftUI

struct Fail6a1: View {
    var body: some View {
        let title = "Hello"
        Text(title)
        print("rendered")
    }
}
⚠️

body に print を書くとビルドが失敗する

Terminal 
$ xcodebuild -project HandsonApp.xcodeproj -scheme HandsonApp -destination 'platform=iOS Simulator,name=iPhone 17' -derivedDataPath $DD build……/Views/Fail6a1.swift:7:9: error: type '()' cannot conform to 'View' [#ProtocolTypeNonConformance]** BUILD FAILED **

type '()' cannot conform to 'View'（() 型は View に準拠できない）のエラーが、print("rendered") の行（7 行目）で出ます。 ViewBuilder の中では、print(…) の結果（何も返さないことを表す () 型）も View の並びの 1 つとして扱われるためです。 一方、let title = "Hello" のような let 文は、ViewBuilder の中でも書けます。

確認したら、実験用のファイルを削除して、ビルドが通る状態に戻します。

Terminal 
$ rm HandsonApp/Views/Fail6a1.swift

✅ 確認ポイント

Text を 2 つ並べただけではビルドが通り、print を混ぜると type '()' cannot conform to 'View' でビルドが失敗することを確認できれば OK です。最後に Fail6a1.swift を削除したことも確かめてください。

つまずきポイント

💡

背景が思った範囲に付かない

修飾子の順序を確認してください。.padding() や .frame(maxWidth: .infinity) を .background より前に書くと、余白や広げた範囲まで背景が付きます。後ろに書くと、背景は元の View の範囲だけに付きます。

💡

Status を == で比べられない

関連値（.done(Date)）を持つ Status は Equatable ではないため、item.status == .todo のようには書けません。ステップ 5 の TodoRow のように、switch か if case .done = item.status で判定してください。
