List と NavigationStack

  • ⏱ 所要時間: 45分
  • 📊 難易度: 入門
  • 👤 対象: SwiftUI で状態を持つ 1 画面のアプリを作れ、次に一覧から詳細画面へ遷移するアプリを作りたい人
  • 📋 前提: 04 で TodoStore を @Environment で注入した HandsonApp プロジェクトが手元にあること。@State・@Binding・@Bindable と、プロトコル・関連値付きの enum を知っていること
  • 🔗 前提となる項目: 04 @State・@Binding・@Observable

🎯 このレッスンで学ぶこと

  • Identifiable に準拠したモデルを ForEach に id: 無しで渡す
  • List と Section で、見出し付きの一覧画面を組み立てる
  • NavigationStack に .navigationTitle と .toolbar（EditButton）を付ける
  • NavigationLink(value:) と .navigationDestination(for:) で詳細画面へ遷移する
  • .onDelete・.onMove と IndexSet で、行の削除と並べ替えを実装する
  • Identifiable・.navigationDestination・NavigationStack の扱いを誤ったときのエラーや症状を確かめる

概要

04 で作った ToDo の画面を List に置き換え、NavigationStack で画面遷移できるようにします。 完成すると、タイトル「ToDo」の付いた一覧から行をタップして詳細画面へ進み、戻るボタンで一覧へ戻れるようになります。右上の「Edit」ボタンで編集モードに入ると、行の削除と並べ替えもできます。

Identifiable・List → NavigationStack → NavigationLink・詳細画面 → 削除・並べ替え、の順に 1 ステップずつ進めます。 最後に、つまずきやすい 3 つの誤りを意図的に起こして、エラーや症状を確かめます。 04 と同じく、Xcode の画面での操作と、同じ結果をターミナルで確かめるコマンドの両方を載せています。

2

Identifiable と List で一覧を作る

04 では ForEach($store.items, id: \.title) のように、行を区別するキーとしてタイトルを指定していました。この方法では、同じタイトルの ToDo を追加すると ID が重複します。 そこで、TodoItem に一意な ID を持たせ、Identifiable プロトコルに準拠させます。Models/TodoItem.swift の TodoItem の宣言を次のように変えます。

  • Identifiable: 要件は id プロパティを持つことだけです。id の型は Hashable である必要があり、UUID はこれを満たします。
  • let id = UUID(): デフォルト値付きの let は、メンバーワイズイニシャライザーの引数になりません。そのため TodoItem(title:priority:status:) の呼び出しは、アプリもテストも書き換える必要はありません。
  • インスタンスを作るたびに別の id が割り当てられます。タイトルが同じ ToDo を 2 つ作っても、別の行として扱われます。

次に、ContentView の VStack を List に置き換えます。List はスクロールできる一覧で、中身を Section で区切れます。 04 で VStack に並べていた部品を、プロフィールとボタン・トグル、ToDo の一覧、追加欄の 3 つの Section に分けます。ContentView.swift 全体を次の内容に書き換えます。

Swift HandsonApp/ContentView.swift 
//
//  ContentView.swift
//  HandsonApp
//

import SwiftUI

struct ContentView: View {
    let profile = Profile(name: "Taro Yamada", nickname: "Taro")

    @Environment(TodoStore.self) private var store

    @State private var tapCount = 0
    @State private var showsDone = true
    @State private var newTitle = ""

    private var canAdd: Bool {
        (try? validate(name: newTitle)) != nil
    }

    var body: some View {
        @Bindable var store = store
        List {
            Section {
                ProfileHeader(profile: profile)

                Button("タップ回数: \(tapCount)") {
                    tapCount += 1
                }
                .buttonStyle(.borderless)

                Toggle("完了も表示", isOn: $showsDone)
            }

            Section("Todo") {
                ForEach($store.items) { $item in
                    if showsDone || !item.isDone {
                        TodoRow(item: $item)
                    }
                }
            }

            Section("追加") {
                HStack {
                    TextField("新しいタスク", text: $newTitle)
                    Button("追加") {
                        store.add(title: newTitle)
                        newTitle = ""
                    }
                    .buttonStyle(.borderless)
                    .disabled(!canAdd)
                }
            }
        }
    }
}

4

NavigationLink で詳細画面へ遷移する

行をタップしたときに表示する詳細画面を作ります。Views フォルダに SwiftUI の View のファイル TodoDetailView.swift を作ります。Xcode では Views を右クリックし、New File from Template… で iOS > SwiftUI View を選びます（Targets は HandsonApp）。 中身を次の内容に書き換えます。

Swift HandsonApp/Views/TodoDetailView.swift 
import SwiftUI

struct TodoDetailView: View {
    let item: TodoItem

    var body: some View {
        List {
            LabeledContent("タイトル", value: item.title)
            LabeledContent("優先度", value: item.priority.label)
            LabeledContent("状態", value: item.isDone ? "完了" : "未完了")
            if case .done(let date) = item.status {
                LabeledContent("完了日時") {
                    Text(date, format: .dateTime.year().month().day().hour().minute())
                }
            }
        }
        .navigationTitle(item.title)
        .navigationBarTitleDisplayMode(.inline)
    }
}

  • if case .done(let date) = item.status: .done の関連値（完了日時）を取り出します。未完了のときは「完了日時」の行ごと表示しません。
  • .navigationBarTitleDisplayMode(.inline): 詳細画面のタイトルを、大きな見出しではなくナビゲーションバーの中央に小さく表示します。

⚠️

ℹ️

行の onTapGesture が NavigationLink のタップを奪う

04 の TodoRow は、行全体に .onTapGesture { item.toggle() } を付けていました。この行を NavigationLink で包むと、タップは TodoRow の onTapGesture が受け取ります。 そのため「牛乳を買う」の行をタップすると、詳細画面には進まず、行が完了（緑のチェックマークと取り消し線）に切り替わるだけです。

そこで、行全体のタップは NavigationLink に任せ、完了・未完了の切り替えは左端のアイコンをボタンにして行います。

Views/TodoRow.swift を次の内容に書き換えます。

Swift HandsonApp/Views/TodoRow.swift 
import SwiftUI

struct TodoRow: View {
    @Binding var item: TodoItem

    var body: some View {
        HStack(spacing: 12) {
            // 完了の切り替えはアイコンのボタンだけに任せる（行のタップは NavigationLink に譲る）
            Button {
                item.toggle()
            } label: {
                // switch: Status の case ごとにアイコンを切り替える
                switch item.status {
                case .todo:
                    Image(systemName: "circle")
                        .foregroundStyle(.secondary)
                case .done:
                    Image(systemName: "checkmark.circle.fill")
                        .foregroundStyle(.green)
                }
            }
            .buttonStyle(.borderless)
