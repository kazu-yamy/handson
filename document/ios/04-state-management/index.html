@State・@Binding・@Observable

  • ⏱ 所要時間: 45分
  • 📊 難易度: 入門
  • 👤 対象: SwiftUI で表示だけの画面を組み立てられ、次にタップや入力で画面を変えたい人
  • 📋 前提: 03 で ProfileHeader・TodoRow を作った HandsonApp プロジェクトが手元にあること。構造体とクラスの違い、mutating の意味を知っていること
  • 🔗 前提となる項目: 03 SwiftUI 入門

🎯 このレッスンで学ぶこと

  • @State で View が所有する値を持ち、ボタンやトグルの操作で書き換える
  • @Binding と $ で親の状態を子の View に渡し、子から書き換える
  • @Observable の参照型のモデル（TodoStore）を作り、@State で所有する
  • @Environment でモデルを注入し、@Bindable で Binding を取り出す
  • @State・$・@Bindable・.environment を忘れたときのエラーやクラッシュの文言を確かめる

概要

03 で作った「データを表示するだけの画面」に、操作で変わる状態を加えます。 完成すると、タップ回数を数えるボタン、完了済みの ToDo を隠すトグル、行のタップによる完了・未完了の切り替え、テキストフィールドからの ToDo の追加ができるようになります。

状態の持ち方を、@State（View が所有する値）→ @Binding（親の状態への参照）→ @Observable（参照型のモデル）→ @Environment（モデルの注入）の順に、1 ステップに 1 つずつ導入します。 03 と同じく、Xcode の画面での操作と、同じ結果をターミナルで確かめるコマンドの両方を載せています。

ℹ️

使用バージョン

03 と同じく、macOS 26.6.2 / Xcode 27.0 / Swift 6.4 で動作を確認しています。シミュレータは iPhone 17（iOS 26.5）を使います。 バージョンは執筆時点（2026年10月）のものです。

2

@State でボタンとトグルを動かす

まず、ボタンを押した回数を画面に表示します。回数は ContentView のプロパティに持たせます。 試しに、ContentView.swift の items の下にふつうの var を足し、ProfileHeader の下にボタンを置いてビルドしてみます。

⚠️

@State を付けないとプロパティを書き換えられない

Terminal 
$ xcodebuild -project HandsonApp.xcodeproj -scheme HandsonApp -destination 'platform=iOS Simulator,name=iPhone 17' -derivedDataPath $DD build……/ContentView.swift:24:26: error: left side of mutating operator isn't mutable: 'self' is immutable** BUILD FAILED **

left side of mutating operator isn't mutable: 'self' is immutable（+= の左辺が変更できない。self が変更不可）のエラーです。 View は構造体で、body は mutating ではありません。そのため、body の中のボタンのアクションから、値型のプロパティは書き換えられません。

@State を付けると、値は View の外（SwiftUI が管理する保存領域）に置かれ、body の中から書き換えられるようになります。値が変わると SwiftUI が body を再評価し、画面が更新されます。 ボタンに加えて、完了済みの ToDo を表示するかどうかを切り替えるトグルも追加します。ContentView.swift 全体を次の内容に書き換えます。 03 にあった「Todo はありません」の表示と List についてのコメントは、ここで外します。items は固定の 3 件で空にならないため、空のときの表示は不要です。List は次の 05 で扱うので、そのコメントも外します。

Swift HandsonApp/ContentView.swift 
//
//  ContentView.swift
//  HandsonApp
//

import SwiftUI

struct ContentView: View {
    let profile = Profile(name: "Taro Yamada", nickname: "Taro")

    let items: [TodoItem] = [
        TodoItem(title: "牛乳を買う", priority: .high),
        TodoItem(title: "メールを返す", priority: .low, status: .done(Date())),
        TodoItem(title: "SwiftUI を勉強する"),
    ]

    @State private var tapCount = 0
    @State private var showsDone = true

    private var visibleItems: [TodoItem] {
        items.filter { item in
            if case .done = item.status {
                return showsDone
            }
            return true
        }
    }

    var body: some View {
        VStack(alignment: .leading, spacing: 16) {
            ProfileHeader(profile: profile)

            Button("タップ回数: \(tapCount)") {
                tapCount += 1
            }

            Toggle("完了も表示", isOn: $showsDone)

            Text("Todo")
                .font(.headline)

            VStack(alignment: .leading, spacing: 12) {
                ForEach(visibleItems, id: \.title) { item in
                    TodoRow(item: item)
                }
            }

            Spacer()
        }
        .padding()
    }
}

#Preview {
    ContentView()
}
  • @State private var tapCount = 0: この View が所有する状態です。その View だけが持つ値なので、private にするのが慣例です。
  • Button("タップ回数: \(tapCount)") { tapCount += 1 }: 1 つ目の引数がボタンの文字、後ろのクロージャが押したときのアクションです。@State の値の書き換えは、このようなアクションの中で行います。body の中で直接書き換える（描画の途中で状態を変える）ことは避けます。
  • Toggle("完了も表示", isOn: $showsDone): $showsDone は Binding<Bool> 型の値です。@State のプロパティに $ を付けると、値そのものではなく、値を読み書きするための参照（Binding）が得られます。Toggle はこの Binding を通して showsDone を書き換えます。
  • visibleItems: showsDone が false のときは、.done の ToDo を除いた配列を返します。ForEach はこの配列を表示します。
ℹ️

@State の初期値が保存されるのは最初の 1 回だけ

= 0 や = true の初期値の式は、View が作られるたびに評価されます。ただし状態として保存されるのは最初の 1 回だけで、以後は保存された値が使われます。 View の構造体は描画のたびに作り直されますが、そのたびに状態が初期値へ戻るわけではありません。

3

@Binding で子の View から親の状態を書き換える

次に、ToDo の行をタップして完了・未完了を切り替えます。ToDo の配列は ContentView（親）が持ち、タップを受けるのは TodoRow（子）です。 子から親の状態を書き換えるには、親が値の代わりに Binding を渡し、子は @Binding で受け取ります。

まず、モデルの TodoItem に、完了かどうかを返す isDone と、状態を反転する toggle() を追加します。Models/TodoItem.swift の statusText の前に 2 つのメンバーを足し、次の内容にします。

Swift HandsonApp/Models/TodoItem.swift 
import Foundation

enum Priority: Int, CaseIterable {
    case low = 1
    case medium
    case high

    var label: String {
        switch self {
        case .low: "低"
        case .medium: "中"
        case .high: "高"
        }
    }
}

// 関連値付きの enum
enum Status {
    case todo
    case done(Date)
}

struct TodoItem {
    let title: String
    var priority: Priority = .medium
    var status: Status = .todo

    var isDone: Bool {
        if case .done = status {
            return true
        }
        return false
    }

    mutating func toggle() {
        switch status {
        case .todo:
            status = .done(Date())
        case .done:
            status = .todo
        }
    }

    var statusText: String {
        switch status {
        case .todo:
            "未完了"
        case .done(let date):
            "完了 (\(date.formatted(.iso8601.year().month().day())))"
        }
    }
}
  • var isDone: Bool: 03 では TodoRow の中に private var isDone がありました。ContentView の絞り込みでも使うため、TodoItem に移します。
  • mutating func toggle(): .todo なら現在日時で .done に、.done なら .todo に戻します。構造体の status を書き換えるので mutating が必要です。

Views/TodoRow.swift を次の内容に書き換えます。03 からの変更点は、item を @Binding で受け取ること、タップで item.toggle() を呼ぶこと、isDone を TodoItem のものに替えたこと、プレビューの書き方の 4 つです。

Swift HandsonApp/Views/TodoRow.swift 
import SwiftUI

struct TodoRow: View {
    @Binding var item: TodoItem

    var body: some View {
        HStack(spacing: 12) {
            // switch: Status の case ごとにアイコンを切り替える
            switch item.status {
            case .todo:
                Image(systemName: "circle")
                    .foregroundStyle(.secondary)
            case .done:
                Image(systemName: "checkmark.circle.fill")
                    .foregroundStyle(.green)
            }

            Text(item.title)
                .strikethrough(item.isDone)

            Spacer()

            Text(item.priority.label)
                .font(.caption)
                .padding(.horizontal, 8)
                .padding(.vertical, 2)
                .background(.quaternary, in: Capsule())
        }
        .contentShape(Rectangle())
        .onTapGesture {
            item.toggle()
        }
    }
}

#Preview("未完了") {
    @Previewable @State var item = TodoItem(title: "牛乳を買う", priority: .high)
    TodoRow(item: $item)
        .padding()
}

#Preview("完了") {
    @Previewable @State var item = TodoItem(title: "メールを返す", priority: .low, status: .done(Date()))
    TodoRow(item: $item)
        .padding()
}

4

@Observable でモデルをクラスにまとめる（TodoStore）

ToDo の配列と、それに対する操作（追加・切り替え）を、View から切り離したモデルにまとめます。 @Observable マクロを付けたクラスは、プロパティの変更を SwiftUI に伝えられる参照型のモデルになります。 Models フォルダに Swift ファイル TodoStore.swift を作ります。Xcode では Models を右クリックし、New File from Template… で iOS > Swift File を選びます（Targets は HandsonApp）。

Swift HandsonApp/Models/TodoStore.swift 
import Foundation
import Observation

@Observable
final class TodoStore {
    var items: [TodoItem]

    init(items: [TodoItem] = []) {
        self.items = items
    }

    func add(title: String, priority: Priority = .medium) {
        items.append(TodoItem(title: title, priority: priority))
    }

    func toggle(_ item: TodoItem) {
        guard let index = items.firstIndex(where: { $0.title == item.title }) else { return }
        items[index].toggle()
    }

    static let sample = TodoStore(items: [
        TodoItem(title: "牛乳を買う", priority: .high),
        TodoItem(title: "メールを返す", priority: .low, status: .done(Date())),
        TodoItem(title: "SwiftUI を勉強する"),
    ])
}
  • @Observable final class TodoStore: @Observable は Observation フレームワークのマクロです（import SwiftUI しているファイルでも使えます）。
  • add(title:priority:): 優先度を省略すると .medium の ToDo を末尾に追加します。ステップ 5 で使います。
  • toggle(_:): TodoItem は Identifiable ではないため、title で検索して切り替えます。同じタイトルが複数あると、先頭の 1 件だけが切り替わります。見つからなければ何もしません。
  • static let sample: 03 から使っている 3 件の ToDo を入れたストアです。アプリとプレビューの両方で使います。
ℹ️

ObservableObject と Combine は使わない

@Observable 以前は、ObservableObject に準拠したクラスのプロパティに @Published を付けていました。View 側では @StateObject・@ObservedObject を使います（Combine ベースの書き方）。 この教材では旧世代の書き方として扱い、使いません。@Observable のクラスを View が所有するときは、@StateObject ではなく @State を使います。

Swift 6 と @MainActor

6

@Environment でストアをアプリ全体に渡す

今は ContentView が TodoStore を作って所有しています。画面が増えると、複数の View から同じストアを使いたくなります。 そこで、ストアの生成をアプリのルート（HandsonAppApp）に移し、.environment(_:) で View の階層に注入します。下の View は @Environment で受け取ります。 HandsonAppApp.swift を次の内容にします。

Swift HandsonApp/HandsonAppApp.swift 
//
//  HandsonAppApp.swift
//  HandsonApp
//

import SwiftUI

@main
struct HandsonAppApp: App {
    @State private var store = TodoStore.sample

    var body: some Scene {
        WindowGroup {
            ContentView()
                .environment(store)
        }
    }
}
  • @State private var store = TodoStore.sample: アプリのルートがストアを所有します。生成は 1 回だけです。
  • .environment(store): ContentView とその下の全ての View から、TodoStore を取り出せるようにします。

ContentView.swift は、@State のストアを @Environment に置き換えます。完成形の全文は次のとおりです。

Swift HandsonApp/ContentView.swift 
//
//  ContentView.swift
//  HandsonApp
//

import SwiftUI

struct ContentView: View {
    let profile = Profile(name: "Taro Yamada", nickname: "Taro")

    @Environment(TodoStore.self) private var store

    @State private var tapCount = 0
    @State private var showsDone = true
    @State private var newTitle = ""

    private var canAdd: Bool {
        (try? validate(name: newTitle)) != nil
    }

    var body: some View {
        @Bindable var store = store
        VStack(alignment: .leading, spacing: 16) {
            ProfileHeader(profile: profile)

            Button("タップ回数: \(tapCount)") {
                tapCount += 1
            }

            Toggle("完了も表示", isOn: $showsDone)

            Text("Todo")
                .font(.headline)

            VStack(alignment: .leading, spacing: 12) {
                ForEach($store.items, id: \.title) { $item in
                    if showsDone || !item.isDone {
                        TodoRow(item: $item)
                    }
                }
            }

            HStack {
                TextField("新しいタスク", text: $newTitle)
                    .textFieldStyle(.roundedBorder)
                Button("追加") {
                    store.add(title: newTitle)
                    newTitle = ""
                }
                .disabled(!canAdd)
            }

            Spacer()
        }
        .padding()
    }
}

}

まとめ

@State で View が所有する値を持ち、@Binding と $ で子の View から親の状態を書き換えました。 さらに、ToDo の配列と操作を @Observable の TodoStore にまとめました。TodoStore はアプリのルートで所有して .environment で注入し、@Environment と @Bindable で受け取りました。 あわせて、@State・$・@Bindable の付け忘れはビルドエラーになり、.environment の付け忘れは起動時のクラッシュになることも確かめました。 次の項目では、List と NavigationStack を使い、一覧から詳細画面へ遷移する画面を作ります。
