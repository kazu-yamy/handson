WidgetKit と App Intents

  • ⏱ 所要時間: 60分
  • 📊 難易度: 中級
  • 👤 対象: SwiftData で保存する ToDo アプリを作ったことがあり、その内容をホーム画面のウィジェットとショートカットアプリから扱えるようにしたい人
  • 📋 前提: 09 で Swift Testing のテストを整えた HandsonApp プロジェクトが手元にあること。SwiftData の ModelContainer・ModelContext・FetchDescriptor と、Swift Testing の @Suite・@Test を使ったことがあること
  • 🔗 前提となる項目: 09 Swift Testing

🎯 このレッスンで学ぶこと

  • AppIntent でアプリの操作を定義し、AppShortcutsProvider でショートカットアプリに登録する
  • Widget Extension のターゲットを追加し、WidgetBundle が拡張の入り口になることを理解する
  • StaticConfiguration・TimelineProvider・TimelineEntry でウィジェットの表示内容を組み立てる
  • App Group と ModelConfiguration(groupContainer:) で、アプリとウィジェットが同じデータベースを読む
  • WidgetCenter.shared.reloadAllTimelines() で、アプリの変更をウィジェットに反映する
  • Button(intent:) で、ウィジェットのボタンから Intent を実行する
  • Intent の処理をユニットテストで確かめる

概要

08 から SwiftData で保存している ToDo アプリへ、ホーム画面のウィジェットとショートカットを加えます。ウィジェットは未完了の件数と新しい ToDo のタイトルを表示し、最新の ToDo を完了にするボタンも置きます。ショートカットアプリには「ToDo を追加」のショートカットを登録します。

ウィジェットは、アプリとは別の「拡張（App Extension）」として、別のプロセスで動きます。そのため、アプリのデータベースをそのままでは読めません。App Group という共有の保存場所を使い、アプリとウィジェットが同じデータベースを開くようにします。 1 ステップで扱う概念は 1 つです。完成すると、ユニットテストは 73 から 76 に増えます。

ℹ️

使用バージョンと並行処理の設定

Xcode 27.0 / Swift 6.4 / iPhone 17（iOS 27.0）のシミュレータは 09 と同じです。バージョンは執筆時点（2026年10月）のものです。WidgetKit と App Intents は SDK に含まれているので、追加のパッケージは要りません。

アプリターゲットは 09 と同じく、SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor です。ステップ 2 で追加するウィジェットのターゲットにはこの設定が無く、型は既定でメインアクターの外（nonisolated）にあります。 アプリとウィジェットの両方に入れるファイルでは、この違いを意識します（ステップ 4）。

この項目の手順は、シミュレータで動かす前提です。開発チーム（Team）を設定していない状態で、App Group を含めて動作を確かめました。

手順

1

AppIntent と AppShortcutsProvider でショートカットを作る

App Intents は、アプリの操作を「Intent」という型で宣言し、ショートカットアプリや Siri、ウィジェットから呼べるようにする仕組みです。まず、ToDo を 1 件追加する Intent を作ります。 HandsonApp フォルダに Intents フォルダを作り、AddTodoIntent.swift を追加して次の内容にします（Targets は HandsonApp）。

Swift HandsonApp/Intents/AddTodoIntent.swift（ステップ 1 の版） 
import AppIntents
import SwiftData

// ショートカットや Siri から ToDo を追加する
struct AddTodoIntent: AppIntent {
    static let title: LocalizedStringResource = "ToDo を追加"

    @Parameter(title: "タイトル")
    var todoTitle: String

    @MainActor
    func perform() async throws -> some IntentResult & ProvidesDialog {
        let container = try ModelContainer(for: TodoRecord.self)
        try addTodo(title: todoTitle, in: container.mainContext)
        return .result(dialog: "「\(todoTitle)」を追加しました")
    }
}

// テストからも呼べるよう、保存処理は関数に分ける
func addTodo(title: String, in context: ModelContext) throws {
    context.insert(TodoRecord(title: title))
    try context.save()
}
  • AppIntent に準拠した型が 1 つの操作です。title はショートカットアプリなどに表示される名前です。
  • @Parameter(title: "タイトル"): Intent が実行時に受け取る値です。title は、ショートカットアプリなどで値を表す名前になります。
  • perform(): Intent の本体です。戻り値の ProvidesDialog は、実行後にダイアログ（ここでは「「…」を追加しました」）を表示することを表します。
  • この時点では、08 と同じ ModelContainer(for:)（アプリの保存場所）を開きます。ステップ 4 で、ウィジェットと共有する保存場所に切り替えます。
  • 保存の処理は addTodo(title:in:) という関数に分けます。ステップ 7 で、この関数をメモリ上のコンテナに対してテストします。
⚠️

perform() の @MainActor を付け忘れると、ビルドが通らない

@MainActor の行を消してビルドすると、次の 2 つのエラーになります。

Terminal 
AddTodoIntent.swift:13:53: error: non-Sendable type 'ModelContext' of property 'mainContext' cannot exit main actor-isolated context [#NonSendableExitingActor]AddTodoIntent.swift:13:9: error: expression is 'async' but is not marked with 'await'** BUILD FAILED **

ModelContainer の mainContext はメインアクターに分離されています。アプリターゲットは既定でメインアクターですが、AppIntent の perform() はプロトコルの要件の都合で既定では分離されず、そこから mainContext に触れないためです。 @MainActor を戻すとビルドが通ります。

次に、この Intent をショートカットとして登録します。同じ Intents フォルダに TodoShortcuts.swift を追加します（Targets は HandsonApp）。

Swift HandsonApp/Intents/TodoShortcuts.swift 
import AppIntents

struct TodoShortcuts: AppShortcutsProvider {
    static var appShortcuts: [AppShortcut] {
        AppShortcut(
            intent: AddTodoIntent(),
            phrases: ["\(.applicationName) に ToDo を追加"],
            shortTitle: "ToDo を追加",
            systemImageName: "plus.circle"
        )
    }
}
  • AppShortcutsProvider に準拠した型の appShortcuts に並べた Intent は、アプリをインストールしただけでショートカットアプリに表示されます。利用者がショートカットを自分で作る必要はありません。
  • phrases は Siri に話しかけるときの言い回しです。\(.applicationName)（アプリ名）を必ず含めます。
  • shortTitle と systemImageName は、ショートカットアプリのタイルに表示される名前と SF Symbols のアイコンです。
  • AppShortcutsProvider はアプリに 1 つだけ置きます。この型はアプリ専用で、ステップ 2 で追加するウィジェットには入れません。

ビルドすると、Intent とショートカットの情報が .app の中の Metadata.appintents/extract.actionsdata（JSON）に書き出されます。中身を python3 で表示して確かめます。

2

Widget Extension のターゲットを追加する

ウィジェットは、アプリに埋め込む拡張（App Extension）として作ります。拡張はアプリとは別のターゲットで、ビルドすると .appex というバンドルになり、アプリの .app の中に入ります。 Xcode で次の順に操作して、ターゲットを追加します。

  1. メニューの File > New > Target… を選びます。
  2. iOS の一覧から Widget Extension を選びます。
  3. 設定を次のとおりにします。
    • Product Name: TodoWidget
    • Include Live Activity: オフ
    • Include Control: オフ
    • Include Configuration App Intent: オフ
    • Embed in Application: HandsonApp
  4. Finish をクリックしてターゲットを作成します。
  • 3 つの Include … は、既定では全てオンです。この項目ではホーム画面のウィジェットだけを作るので、全てオフにします。オンのままにすると、この項目で使わないファイルが追加されます。
  • Product Name に TodoWidget と入れると、ターゲット名は TodoWidgetExtension、フォルダは TodoWidget/、成果物は TodoWidgetExtension.appex になります。名前が 2 種類あるので注意してください。
  • 作成後に、新しいターゲットのスキームに切り替えるかを尋ねるダイアログが出ることがあります。この項目のビルドと実行は、全てアプリの HandsonApp スキームで行います。ツールバーのスキームが HandsonApp になっていることを確かめてください。

テンプレートは、TodoWidget フォルダに次の 4 つを作ります。この項目では、TodoWidget.swift だけをステップ 3 で書き換え、残りはそのまま使います。消すファイルはありません。

  • TodoWidgetBundle.swift: 拡張の入り口（そのまま使う）
  • TodoWidget.swift: ウィジェットの雛形。絵文字と時刻を表示する Provider / SimpleEntry(date:emoji:) / StaticConfiguration が書かれている（ステップ 3 で全体を書き換える）
  • Assets.xcassets: AccentColor・WidgetBackground・AppIcon（そのまま使う）
  • Info.plist: 拡張の種類を表すキーだけを持つ（そのまま使う）
Swift TodoWidget/TodoWidgetBundle.swift 
//
//  TodoWidgetBundle.swift
//  TodoWidget
//

import WidgetKit
import SwiftUI

@main
struct TodoWidgetBundle: WidgetBundle {
    var body: some Widget {
        TodoWidget()
    }
}
  • 拡張には App がありません。代わりに、@main を付けた WidgetBundle が入り口になります。
  • body に、この拡張が提供するウィジェットを並べます。ウィジェットを増やすときは、ここに 1 行ずつ足します。

3

StaticConfiguration と TimelineProvider で静的なウィジェットを書く

テンプレートの TodoWidget.swift を、ToDo の件数とタイトルを表示するウィジェットに書き換えます。この時点では、データベースはまだ読まず、決まったデータを表示します。 ファイル全体を次の内容に置き換えます。

Swift TodoWidget/TodoWidget.swift（ステップ 3 の版） 
//
//  TodoWidget.swift
//  TodoWidget
//

import SwiftUI
import WidgetKit

// ウィジェットに表示する内容（ステップ 4 で共有ファイルへ移す）
struct TodoSnapshot: Equatable, Sendable {
    let remaining: Int
    let titles: [String]
}

struct TodoEntry: TimelineEntry {
    let date: Date
    let snapshot: TodoSnapshot
}

struct Provider: TimelineProvider {
    func placeholder(in context: Context) -> TodoEntry {
        loadEntry()
    }

    func getSnapshot(in context: Context, completion: @escaping (TodoEntry) -> Void) {
        completion(loadEntry())
    }

    func getTimeline(in context: Context, completion: @escaping (Timeline<TodoEntry>) -> Void) {
        // 更新は自分で依頼する（.never）。ここでは固定のデータを 1 件だけ返す
        completion(Timeline(entries: [loadEntry()], policy: .never))
    }

    private func loadEntry() -> TodoEntry {
        TodoEntry(date: .now, snapshot: TodoSnapshot(remaining: 2, titles: ["牛乳を買う", "本を返す"]))
    }
}

struct TodoWidgetEntryView: View {
    var entry: TodoEntry

    var body: some View {
        VStack(alignment: .leading, spacing: 4) {
            Text("残り \(entry.snapshot.remaining) 件")
                .font(.headline)
            ForEach(entry.snapshot.titles.indices, id: \.self) { index in
                Text(entry.snapshot.titles[index])
                    .font(.caption)
                    .lineLimit(1)
            }
        }
        .frame(maxWidth: .infinity, alignment: .leading)
    }
}

struct TodoWidget: Widget {
    let kind: String = "TodoWidget"

    var body: some WidgetConfiguration {
        StaticConfiguration(kind: kind, provider: Provider()) { entry in
            TodoWidgetEntryView(entry: entry)
                .containerBackground(.fill.tertiary, for: .widget)
        }
        .configurationDisplayName("ToDo")
        .description("未完了の ToDo を表示します。")
        .supportedFamilies([.systemSmall, .systemMedium])
    }
}

#Preview(as: .systemSmall) {
    TodoWidget()
} timeline: {
    TodoEntry(date: .now, snapshot: TodoSnapshot(remaining: 2, titles: ["牛乳を買う", "本を返す"]))
}

ウィジェットは、次の 3 つの部品で組み立てます。

  • TimelineEntry（TodoEntry）: ある時刻に表示する内容です。date（表示を始める時刻）が必須で、表示に使う値（ここでは TodoSnapshot）を自由に足します。
  • TimelineProvider（Provider）: エントリーを作ってシステムに渡します。placeholder はデータが届く前の仮の表示、getSnapshot はウィジェットギャラリーなどで使う 1 件、getTimeline はホーム画面に表示するエントリーの並び（タイムライン）です。ここでは 3 つとも loadEntry() の結果を返します。
  • StaticConfiguration: 利用者が設定する項目の無いウィジェットの構成です。kind はウィジェットを識別する文字列で、provider が作ったエントリーを、クロージャーで View（TodoWidgetEntryView）に渡します。
  • Timeline(entries:policy: .never): policy は、次にいつタイムラインを作り直すかの指定です。.never は、システムからは作り直さず、アプリから依頼したときだけ作り直します（ステップ 5）。
  • .containerBackground(.fill.tertiary, for: .widget): ウィジェットの背景の指定です。テンプレートと同じ書き方です。
  • .configurationDisplayName と .description は、ウィジェットギャラリーに表示される名前と説明です。.supportedFamilies で、小（.systemSmall）と中（.systemMedium）のサイズに対応します。
  • TodoSnapshot は、表示する内容（未完了の件数とタイトル）をまとめた型です。ステップ 4 で、アプリと共有するファイルに移します。
  • 末尾の #Preview(as: .systemSmall) は、Canvas でウィジェットをプレビューするためのものです。テンプレートにも付いています。

Swift HandsonApp/Shared/SharedStore.swift 
import Foundation
import SwiftData

// アプリとウィジェットで同じデータベースを開くための設定
nonisolated enum SharedStore {
    static let appGroupID = "group.com.example.HandsonApp"

    static func makeContainer(inMemory: Bool = false) throws -> ModelContainer {
        let configuration = inMemory
            ? ModelConfiguration(isStoredInMemoryOnly: true)
            : ModelConfiguration(groupContainer: .identifier(appGroupID))
        return try ModelContainer(for: TodoRecord.self, configurations: configuration)
    }
}

// ウィジェットに表示する内容
nonisolated struct TodoSnapshot: Equatable, Sendable {
    let remaining: Int
    let titles: [String]

    static let empty = TodoSnapshot(remaining: 0, titles: [])
}

extension SharedStore {
    // 未完了の件数と、新しい順の先頭 limit 件のタイトル
    static func snapshot(in context: ModelContext, limit: Int = 3) throws -> TodoSnapshot {
        var descriptor = FetchDescriptor<TodoRecord>(
            predicate: #Predicate { !$0.isDone },
            sortBy: [SortDescriptor(\.createdAt, order: .reverse)]
        )
        let remaining = try context.fetchCount(descriptor)
        descriptor.fetchLimit = limit
        let titles = try context.fetch(descriptor).map(\.title)
        return TodoSnapshot(remaining: remaining, titles: titles)
    }
}
  • ModelConfiguration(groupContainer: .identifier(appGroupID)): データベースを、App Group の共有コンテナに作ります。アプリとウィジェットがこの設定でコンテナを作れば、同じファイルを読み書きします。
  • App Group の ID は appGroupID の 1 か所にまとめます。entitlements の ID と 1 文字でも違うと、共有コンテナを開けません（つまずきポイント）。
  • inMemory: true のときは、09 と同じくメモリ上だけのコンテナを作ります。UI テストとユニットテストで使います。
  • snapshot(in:limit:): 未完了の件数（fetchCount）と、新しい順の先頭 limit 件のタイトルを返します。
  • このファイルは、既定がメインアクターのアプリターゲットと、既定が nonisolated のウィジェットのターゲットの両方でコンパイルされます。nonisolated を明示し、どちらのターゲットでも同じく、メインアクターに縛られない型にしています。

Button(intent:) でインタラクティブなウィジェットにする

ウィジェットにボタンを置き、タップで ToDo を完了にします。ウィジェットのボタンは、クロージャーではなく AppIntent を実行します。 Intents フォルダに CompleteLatestTodoIntent.swift を追加します。

Swift HandsonApp/Intents/CompleteLatestTodoIntent.swift 
import AppIntents
import SwiftData
import WidgetKit

// ウィジェットのボタンから、いちばん新しい未完了の ToDo を完了にする。
// ウィジェット拡張のプロセスで実行されるので、このファイルは両方のターゲットに入れる
struct CompleteLatestTodoIntent: AppIntent {
    static let title: LocalizedStringResource = "最新の ToDo を完了"

    @MainActor
    func perform() async throws -> some IntentResult {
        let container = try SharedStore.makeContainer()
        try completeLatest(in: container.mainContext)
        WidgetCenter.shared.reloadAllTimelines()
        return .result()
    }
}

@MainActor
func completeLatest(in context: ModelContext) throws {
    var descriptor = FetchDescriptor<TodoRecord>(
        predicate: #Predicate { !$0.isDone },
        sortBy: [SortDescriptor(\.createdAt, order: .reverse)]
    )
    descriptor.fetchLimit = 1
    try context.fetch(descriptor).first?.toggle()
    try context.save()
}
  • いちばん新しい未完了の ToDo を 1 件取り出し（fetchLimit = 1）、toggle() で完了にして保存します。
  • ウィジェットから実行した Intent は、perform() から戻るとシステムがタイムラインを読み直します。ここでは保存の後に reloadAllTimelines() を呼び、明示的にも再読み込みを依頼しています。
  • completeLatest(in:) は、addTodo と同じく、テストから呼べるように関数に分けています。

ウィジェットのボタンから実行した Intent は、ウィジェットの拡張のプロセスで動きます。そのため、このファイルは Target Membership で TodoWidgetExtension にもチェックを付け、両方のターゲットに入れます。ステップ 4 の 3 つと合わせて、ウィジェットと共有するファイルは 4 つになります。

import AppIntents
import SwiftData
import SwiftUI
import WidgetKit

struct TodoEntry: TimelineEntry {
    let date: Date
    let snapshot: TodoSnapshot
}

struct Provider: TimelineProvider {
    func placeholder(in context: Context) -> TodoEntry {
        loadEntry()
    }

    func getSnapshot(in context: Context, completion: @escaping (TodoEntry) -> Void) {
        completion(loadEntry())
    }

    func getTimeline(in context: Context, completion: @escaping (Timeline<TodoEntry>) -> Void) {
        // 更新はアプリ側から依頼する（.never）
        completion(Timeline(entries: [loadEntry()], policy: .never))
    }

    // ウィジェットはアプリとは別のプロセス。App Group のストアを開いて読む
    private func loadEntry() -> TodoEntry {
        do {
            let container = try SharedStore.makeContainer()
            let snapshot = try SharedStore.snapshot(in: ModelContext(container))
            return TodoEntry(date: .now, snapshot: snapshot)
        } catch {
            return TodoEntry(date: .now, snapshot: .empty)
        }
    }
}

struct TodoWidgetEntryView: View {
    var entry: TodoEntry

    var body: some View {
        VStack(alignment: .leading, spacing: 4) {
            Text("残り \(entry.snapshot.remaining) 件")
                .font(.headline)
            ForEach(entry.snapshot.titles.indices, id: \.self) { index in
                Text(entry.snapshot.titles[index])
                    .font(.caption)
                    .lineLimit(1)
            }
            if !entry.snapshot.titles.isEmpty {
                // タップすると、ウィジェットのプロセスで Intent が実行される
                Button(intent: CompleteLatestTodoIntent()) {
                    Label("完了", systemImage: "checkmark.circle")
                }
                .font(.caption)
            }
        }
        .frame(maxWidth: .infinity, alignment: .leading)
    }
}

struct TodoWidget: Widget {
    let kind: String = "TodoWidget"

    var body: some WidgetConfiguration {
        StaticConfiguration(kind: kind, provider: Provider()) { entry in
            TodoWidgetEntryView(entry: entry)
                .containerBackground(.fill.tertiary, for: .widget)
        }
        .configurationDisplayName("ToDo")
        .description("未完了の ToDo を表示します。")
        .supportedFamilies([.systemSmall, .systemMedium])
    }
}

Intent の処理をテストし、完成状態を確かめる

Intent の処理を、perform() から分けた関数（addTodo・completeLatest）と SharedStore.snapshot を通してテストします。 HandsonAppTests フォルダに WidgetIntentTests.swift を追加します（Targets は HandsonAppTests）。

Swift HandsonAppTests/WidgetIntentTests.swift 
import Foundation
import SwiftData
import Testing
@testable import HandsonApp

@MainActor
@Suite("ウィジェットと App Intents")
struct WidgetIntentTests {
    // テストごとにメモリ上のコンテナを作る（App Group のストアには触れない）
    let container: ModelContainer

    init() throws {
        container = try SharedStore.makeContainer(inMemory: true)
    }

    @Test func スナップショットは未完了だけを数える() throws {
        let context = container.mainContext
        let done = TodoRecord(title: "済み", createdAt: .now.addingTimeInterval(-30))
        done.toggle()
        context.insert(done)
        context.insert(TodoRecord(title: "古い", createdAt: .now.addingTimeInterval(-20)))
        context.insert(TodoRecord(title: "新しい", createdAt: .now.addingTimeInterval(-10)))

        let snapshot = try SharedStore.snapshot(in: context, limit: 1)
        #expect(snapshot == TodoSnapshot(remaining: 2, titles: ["新しい"]))
    }

    @Test func addTodoで1件増える() throws {
        try addTodo(title: "牛乳を買う", in: container.mainContext)
        let titles = try container.mainContext.fetch(FetchDescriptor<TodoRecord>()).map(\.title)
        #expect(titles == ["牛乳を買う"])
    }

    @Test func completeLatestは最新の未完了を完了にする() throws {
        let context = container.mainContext
        context.insert(TodoRecord(title: "古い", createdAt: .now.addingTimeInterval(-20)))
        context.insert(TodoRecord(title: "新しい", createdAt: .now.addingTimeInterval(-10)))
        try completeLatest(in: context)
        #expect(try SharedStore.snapshot(in: context).titles == ["古い"])
    }
}
  • SharedStore.makeContainer(inMemory: true) で、テストごとにメモリ上のコンテナを作ります。App Group のデータベースには触れません。09 で学んだとおり、init はテストごとに実行されます。
  • テストは、ウィジェットの拡張そのものではなく、アプリのターゲットにある共有のコード（@testable import HandsonApp）を呼びます。ウィジェットに表示する内容は SharedStore.snapshot が決めるので、ここをテストすれば表示する件数とタイトルを確かめられます。
  • import Foundation は、.now.addingTimeInterval などを使うために要ります（SWIFT_UPCOMING_FEATURE_MEMBER_IMPORT_VISIBILITY が有効なため）。

ℹ️

シミュレータでは、ショートカットの実行を確かめられていない

執筆時、シミュレータで ToDo を追加 のタイルをタップすると「Unable to run App Shortcut」と表示され、実行できませんでした。パラメータ（タイトル）を受け取るショートカットで起きており、シミュレータの制約か、パラメータの入力の問題かは切り分けられていません。 そのため、この項目の確認はショートカットアプリに表示されるところまでとし、perform() が呼ぶ保存の処理（addTodo）はユニットテストで確かめています。 実機や Siri からの実行は、このレッスンでは扱いません。

💡

ウィジェットが表示されない（App Group の ID の食い違い）

アプリとウィジェットの entitlements、SharedStore.appGroupID の 3 か所で、App Group の ID が同じかを確かめてください。 執筆時にウィジェット側だけ group.com.example.Typo にしたところ、ウィジェットの拡張が SwiftData の中でクラッシュしました。このクラッシュは do / catch では捕まえられません。そのとき、ログに次の行が出ました。

Terminal 
$ xcrun simctl spawn booted log show --last 5m --predicate 'process == "TodoWidgetExtension"' | grep app_group… container_create_or_lookup_app_group_path_by_app_group_identifier: client is not entitled

ID を正しく戻すと、同じ行が …: success で終わるようになります。

💡

ビルドは成功するのに、インストールで失敗する

TodoWidget/Info.plist の NSExtensionPointIdentifier を確かめてください。com.apple.widgetkit-extension を com.apple.widget-extension と書き間違えても、ビルドは成功します。エラーになるのは、シミュレータへのインストールのときです。

Terminal 
App installation failed: Unable to Install "HandsonApp"…Appex bundle … with id com.example.HandsonApp.TodoWidget does not define either an NSExtensionMainStoryboard or NSExtensionPrincipalClass key with a string value in the NSExtension dictionary in its Info.plist
💡

ウィジェットの件数が変わらない

保存の後に WidgetCenter.shared.reloadAllTimelines() を呼んでいるかを確かめてください。policy: .never のタイムラインは、依頼しない限り作り直されません（ステップ 5）。

まとめ

AppIntent で ToDo を追加する操作を定義し、AppShortcutsProvider でショートカットアプリに登録しました。Widget Extension のターゲットを追加し、WidgetBundle を入り口にしました。ウィジェットは StaticConfiguration・TimelineProvider・TimelineEntry で組み立てました。 アプリとウィジェットは別のプロセスなので、App Group と ModelConfiguration(groupContainer:) で同じデータベースを開きました。保存の後には reloadAllTimelines() で表示の更新を依頼しました。 Button(intent:) でウィジェットからも ToDo を完了にでき、Intent の処理は関数に分けてユニットテストで確かめました。 次の項目では、Swift Charts と MapKit を使います。
